# Render by Blocks

A Blender addon for rendering animations in blocks, with automatic and manual modes, safe pause/resume support, and optional video joining.

## Features

* Render animations in separate blocks.
* Automatic block generation based on the scene frame range and block size.
* Manual block management.
* Automatic and manual rendering modes.
* Safe pause and resume support.
* Continue rendering from the last completed frame.
* Generate MP4 video files using FFmpeg.
* Generate multiple fragments for interrupted or paused blocks.
* Automatically detect existing completed blocks.
* Optional joining of rendered video segments.
* Manifest system for tracking rendered blocks and fragments.
* Dedicated `VIDEOS` folder for generated MP4 files.
* Temporary rendering data stored separately.
* Blender render settings are saved and restored after rendering.
* Blender 5.x media type handling for image and video rendering.
* Keyboard shortcuts and Blender handlers integrated into the addon.

## Requirements

* Blender **5.2 or newer**
* FFmpeg for video encoding and video processing

The addon uses Blender's rendering system and FFmpeg to generate MP4 files.

## Installation

1. Download the latest release of **Render by Blocks**.

2. Open Blender.

3. Go to:

   **Edit → Preferences → Add-ons**

4. Click **Install...**

5. Select the addon `.zip` file.

6. Enable **Render by Blocks**.

After installation, the addon can be used without manually running the Python script in every Blender project.

## Usage

After enabling the addon, open the Render properties in Blender and locate the **Render by Blocks** panel.

### Automatic Mode

In Automatic Mode, the addon creates the blocks from:

* Start frame
* End frame
* Block size

For example, an animation from frame `1` to `300` with a block size of `50` can be divided into:

```text
Block 01 → 1–50
Block 02 → 51–100
Block 03 → 101–150
Block 04 → 151–200
Block 05 → 201–250
Block 06 → 251–300
```

Existing completed blocks can be detected automatically.

### Manual Mode

Manual Mode allows the user to control which blocks should be rendered.

This mode is useful when you want to:

* Select specific blocks.
* Render only selected blocks.
* Pause the process safely.
* Resume the rendering later.
* Continue from the correct frame without unnecessarily starting the block over.

## Pause and Resume

The manual rendering system can temporarily render frames as image files and use FFmpeg to encode the completed segment into an MP4 file.

This allows a block to be interrupted and continued later.

The addon keeps track of rendered segments using a manifest file.

## Output Structure

The addon organizes generated files inside the configured output directory.

The structure is:

```text
 VIDEOS/
├── Video_01.mp4
├── Video_02.mp4
├── Video_03.1.mp4
├── Video_03.2.mp4
└── Video_COMPLETO.mp4
.RPB_TEMP/
 └── temporary rendering data
```

### `VIDEOS`

Contains the MP4 files generated by the addon.

### `.RPB_TEMP`

Contains temporary data used during the rendering process.

### Manifest

The addon also maintains a manifest file in the main output directory to keep track of rendered blocks and fragments.

## FFmpeg

FFmpeg is used to encode video segments and, when requested, join video files.

The addon attempts to locate FFmpeg automatically. If it cannot find FFmpeg, the configured FFmpeg path can be used instead.

## Blender Compatibility

The addon is designed for **Blender 5.2+**.

Blender 5.x separates the media type from the image/video format. The addon handles this when switching between PNG frame rendering and FFmpeg video rendering.
